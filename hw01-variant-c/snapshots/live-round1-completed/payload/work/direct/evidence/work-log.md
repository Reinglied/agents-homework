- LIVE не запускать. Не читать ключи/окружение; никаких OpenSpec-артефактов.

## Реализация

- `SYSTEM` теперь заранее описывает допустимый синтаксис ссылок и требование ссылаться на успешный `read_doc`.
- `run_agent` считает каждую фактическую попытку модели до вызова и возвращает явный `model_error` с событием в трассе при исключении, не повторяя вызов.
- Попытка инструмента учитывается перед диспетчеризацией. Пакет сверх лимита целиком отклоняется без исполнения и без увеличения счётчика. Исключение инструмента превращается в безопасный структурированный `tool_error`; сырой текст исключения не попадает в историю/трассу.
- Успешные tool-ответы связываются с исходным ID вызова; tool-сообщение и событие журнала содержат один и тот же JSON-результат. Успешные поиска и реально возвращённые номера строк учитываются отдельно.
- Добавлен разбор кандидатов ссылок для обеих скобочных форм, ASCII-номеров, положительных значений, порядка диапазона и полного присутствия непрерывного диапазона в успешно прочитанных строках. Ошибка даёт конкретную обратную связь и оставляет модели остаток бюджета для исправления.
- При проверке диапазона сравнивается количество реально доступных строк, без перебора произвольно большого диапазона.
- Первичный вызов `python` через Windows Store alias был заблокирован. Найден уже установленный локальный Python 3.14.4 через `uv python list --only-installed`; проверки выполнены им. Созданный для поиска runtime каталог `evidence/logs/uv-cache` удалён после проверки.
