Статус: материалы подготовлены, запуск закрыт до технической проверки новых контекстов. Исполнители и LIVE не запускались. Пилот находится в ../archive и не изменяется.

Приложение со спецификацией трекера не относится к объёму варианта C.

Читайте protocol.md, matrix.md и contract.md. snapshot.py сохраняет и проверяет снимки.
Запуск самопроверки: `python -m unittest discover -s tests -v` из этой папки.
Две папки ready/direct и ready/with-spec содержат одинаковый стартовый комплект и публичные исполняемые тесты. baseline содержит исходный комплект предыдущего этапа подготовки.
Это подготовленные входы, а не две выполненные разработки.

Проверка соответствия домашке и оставшиеся условия: preflight-review.md. Происхождение входов и хеши: provenance.json.

Пример сохранения завершённого поручения (из experiment-c):
`python snapshot.py create baseline/direct snapshots/direct-first first`
Не используйте этот пример до завершения реализации: исходный комплект не является первым результатом.

Автоматическая обвязка синхронного исполнителя:
`python snapshot.py run <папка-попытки> <новая-папка-снимка> first -- <команда-исполнителя> <аргументы>`
Команда должна завершаться только после завершения поручения, сохранять промпты/историю в evidence и сама соблюдать зафиксированный бюджет. Не передавайте ключи в аргументах. Обвязка сохраняет stdout/stderr и код возврата и создаёт снимок даже при ненулевом коде. Внешний организатор не начинает проверку или исправления при ошибке обвязки/снимка; прерванный процесс не считается сохранённым результатом.

Проверка перед внешней оценкой и перед каждым исправлением:
`python snapshot.py verify <папка-снимка>`
Проверить оба первых снимка, сравнить выведенные SHA-256 манифестов с отдельным журналом организатора. Не давать исполнителю доступ на запись к snapshots.

Зафиксировано: gpt-6-luna / high; точный provider snapshot неизвестен. Публичная и внешняя выборки — по 39 сценариев STUB. План LIVE — 30 запусков, пока NOT RUN. Их результаты не следует смешивать с проверками Python-кода.

Точный порядок запуска и оставшиеся технические условия — LAUNCH.md. Изоляцию новых контекстов и подключение автоматического снимка к выбранному способу запуска нельзя подтвердить одной проверкой файлов. До их фактического подтверждения запуск закрыт. От пользователя дополнительных предметных требований сейчас не нужно.
